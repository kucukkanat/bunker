Available when Bunker uses Microsoft Entra ID sign-in and an admin has [turned on Microsoft 365](/bunker/docs/admin/m365/).

```js
const rows  = await bunker.m365.lists.items('https://corp.sharepoint.com/sites/PMO', 'Projects', { top: 200 });
const range = await bunker.m365.excel.range(fileUrl, 'Budget!A1:F40');
const docs  = await bunker.m365.files.list('https://corp.sharepoint.com/sites/HR/Shared Documents/Policies');
const mgr   = await bunker.m365.graph('/me/manager');
```

## Delegated, viewer-scoped

- Every call runs as **the person viewing the app**, with their own Microsoft 365 permissions. An app can never show someone a list or file they couldn't open in SharePoint themselves.
- Only Graph paths and scopes on the admin's **allowlist** work.
- Tokens stay on the server, encrypted. The page never sees them.
- Every Graph call is audited.

## Consent

The first call may need the viewer to approve extra permissions. It throws `consent_required`; show a friendly message with a button that retries. The shell opens Microsoft's consent prompt and comes back to the app.

```js
try {
  rows = await bunker.m365.lists.items(site, 'Projects');
} catch (err) {
  if (err.code === 'consent_required') showConsentButton(err.message);
  else throw err;
}
```

## API

| | Route (under `/api/v1/sites/{site}`) |
|---|---|
| Any allowlisted Graph GET | `GET /m365/graph?path=` |
| SharePoint list items | `GET /m365/lists/items` |
| Excel range | `GET /m365/excel/range` |
| Files in a folder | `GET /m365/files` |

---
title: bunker.m365
description: Read Microsoft 365 data as the viewer.
sidebar: { order: 6 }
---

Available when your admin has [enabled Microsoft 365](/bunker/docs/admin/m365/). The first call may show the viewer a consent screen. If they decline, the call throws `consent_required`.

```js
// SharePoint list
const rows = await bunker.m365.lists.items('https://corp.sharepoint.com/sites/PMO', 'Projects', { top: 200 });

// Excel range in OneDrive or SharePoint
const range = await bunker.m365.excel.range(fileUrl, 'Budget!A1:F40');

// Files
const docs = await bunker.m365.files.list('https://corp.sharepoint.com/sites/HR/Shared Documents/Policies');

// Raw Graph GET, limited to allowlisted scopes
const me = await bunker.m365.graph('/me/manager');
```

Results are exactly what the **viewer** can see. Two people can open the same page and see different rows.

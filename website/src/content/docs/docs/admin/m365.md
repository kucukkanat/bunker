With `bunker.m365`, a page can read Microsoft 365 data **as the person viewing it**. It never sees more than that person could already open in SharePoint or OneDrive.

## How it works
1. The first time a page asks for M365 data, the viewer sees a Bunker consent screen naming the site and the data it wants.
2. Bunker gets a delegated Graph token for that viewer. Tokens are stored encrypted on the server and never reach the page.
3. Bunker makes the Graph call and returns only the result. Every call is [audited](/bunker/docs/admin/audit/).

## Enabling it
Add delegated Graph permissions to the Bunker app registration and grant admin consent. Then allowlist them:

```sh
BUNKER_M365_SCOPES=Sites.Read.All,Files.Read
```

Pages can only use scopes on this list. Write scopes (`Sites.ReadWrite.All`) are supported but off by default.

## Per-site control
Under **Admin → Microsoft 365**, you can require admin approval before a site can use M365, or limit it to named SharePoint sites.

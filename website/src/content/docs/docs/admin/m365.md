## The model: delegated, viewer-scoped

- Apps call Microsoft Graph **as the person viewing the app**. They see only what that person could already open in SharePoint, OneDrive or Excel.
- Only Graph **scopes on your allowlist** can be requested, for example `Sites.Read.All` and `Files.Read.All`. Read-only scopes are a good start.
- Only Graph **paths** that match the allowlist are forwarded. Writes are off unless you allow them.
- The page never sees a token. Tokens are stored encrypted (AES-256-GCM) on the server.
- **Every Graph call is audited** with the person, the app and the path.

## Set it up

1. In Entra, add the delegated Graph permissions you want to allow to Bunker's app registration, and **grant admin consent** (most `*.Read.All` scopes need it).
2. In *Admin → Microsoft 365* (`PUT /api/v1/admin/m365`), turn it on and list the allowed scopes and paths.
3. The first time someone uses an app that needs a new scope, Bunker asks them to consent (incremental consent), then returns to the app.

## Scopes you might allow

| Scope | Lets apps |
|---|---|
| `Sites.Read.All` | Read SharePoint lists and libraries the viewer can access |
| `Files.Read.All` | Read OneDrive and SharePoint files the viewer can access (Excel ranges too) |
| `Calendars.Read` | Read the viewer's calendar |
| `People.Read` | Read the viewer's frequent contacts |

Start small. Every scope you add is available to every app, with each viewer's permissions.

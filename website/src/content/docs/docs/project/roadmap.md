Bunker v1 ships in five milestones. Each one is usable on its own.

1. **Core:** Entra sign-in, sites, upload, sandbox and CSP, per-site sharing, versions, audit log
2. **Data:** `bunker.db` with live updates, `bunker.files`, `bunker.storage`
3. **AI:** pluggable providers, chat builder, templates, `bunker.ai`
4. **Developers:** CLI, MCP, personal tokens
5. **Microsoft 365:** delegated Graph, consent flow, scope allowlist

Follow progress on [GitHub](https://github.com/kucukkanat/bunker).

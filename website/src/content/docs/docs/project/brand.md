Assets and full guidelines are in [`/brand`](https://github.com/kucukkanat/bunker/tree/master/brand) in the repository.

![Bunker logo](/bunker/favicon.svg)

**A safe place to build.** The brand is calm, warm and dependable.

| Token | Hex |
|---|---|
| Forest (primary) | `#1F3A2E` |
| Moss | `#4F7A63` |
| Paper (background) | `#F7F4EC` |
| Sand | `#E9E3D3` |
| Ink (text) | `#1C211E` |
| Clay (accent, sparingly) | `#C2683F` |

**Type:** Fraunces for headings, Inter for body, JetBrains Mono for code. All are open-source and self-hosted.

**Voice:** plain words, calm confidence, short sentences, and honesty about what's shipped.
